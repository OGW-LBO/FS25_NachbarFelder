# Arbeitsregeln für LS25-Mods

## Kommentare im Code

- Keine erklärenden KI-Kommentare in den Code schreiben: keine Kommentarblöcke über Funktionen, keine Kommentare am Zeilenende, keine Hinweise wie "Build 123: ...", "Wichtig: ...", "verifiziert aus ...".
- Erklärungen gehören in die Antwort an den Nutzer, nicht in die Dateien.
- Gilt für neue Mods und für bestehende: Wird eine bestehende Datei geändert, die vorhandenen KI-Kommentare dieser Datei gleich mit entfernen.
- Erlaubt bleiben nur Texte, die der Spieler sieht (z. B. Hinweise in erzeugten Konfig-XML-Dateien, modDesc-Beschreibung).
- Nach dem Entfernen von Kommentaren die Lua-Syntaxprüfung erneut ausführen.
